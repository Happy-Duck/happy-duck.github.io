## My part

I wrote the Arduino code for two of the room's props, the sticker dispenser and the door of the keg safe. The safe is a lock the players open with a code typed on a keypad; a solenoid holds the door.

## The circuit

<Figure src="/media/courses/info-418/keg-safe-breadboard.webp" alt="A breadboard layout: an Arduino Uno wired to a TIP120 transistor, a solenoid, a bench power supply, a red and a green LED with resistors, a diode, and a piezo buzzer" caption="Keg Safe 2.0 laid out in Tinkercad." />

The parts, and why each is there:

| Part | What it does |
| --- | --- |
| Arduino Uno | Reads the keypad and decides whether the code is right. |
| 4 by 4 keypad | Eight wires, four rows and four columns, scanned to find which key is down. |
| 12 V solenoid | The lock itself. It needs far more current than a pin on the Arduino can supply. |
| TIP120 transistor, 1 kΩ resistor | The Arduino switches the transistor, and the transistor switches the solenoid's 12 V. |
| Diode across the solenoid | A coil pushes back when it is switched off. The diode gives that current a path that is not the transistor. |
| Red and green LEDs, 220 Ω each | Two status lights. |
| Piezo buzzer, small transistor | Sound, driven the same way as the solenoid but at a smaller scale. |
| 0.1 µF capacitor | Across the 12 V supply, to smooth it. |
