## How it works

Boxes joined by arrows. `col` and `row` say where each box sits, counting
from 0:

<Diagram
  caption="What the diagram shows."
  nodes={[
    { id: 'a', label: 'First box', note: 'a second line', col: 0, row: 0 },
    { id: 'b', label: 'Second box', col: 1, row: 0 },
    { id: 'c', label: 'Third box', col: 2, row: 0 },
  ]}
  links={[
    { from: 'a', to: 'b', label: 'what flows' },
    { from: 'b', to: 'c' },
  ]}
/>

Code is highlighted automatically. Put the language after the backticks:

```cs
void Update() {
    transform.position += velocity * Time.deltaTime;
}
```

A chart. `type` is `line`, `bar`, or `scatter`:

  unit="downloads"

  series={[{ name: 'Downloads', values: [120, 900, 2400] }]}
  caption="Where the numbers come from."
